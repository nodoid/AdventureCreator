# Adventure System — User Guide

Version 1.0 · Copyright © 2026 Paul F.Johnson

publishing games as standalone apps.

**Quick start:** open the Studio, choose **File › Open Example: The Lighthouse**, then **Adventure › Test Play** (⌘R).
Play a few moves, then look at the Rooms, Items and Triggers sections to see how the game is built.

Keyboard shortcuts in this guide use macOS symbols. On Windows, use **Ctrl** instead of **⌘** and **Alt** instead of **⌥**.
