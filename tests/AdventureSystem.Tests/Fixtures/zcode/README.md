# Z-machine test programs

Used by the Z-machine tests. Both are standard conformance tests for Z-machine interpreters, from the IF Archive
(https://ifarchive.org/if-archive/infocom/interpreters/tools/).

* **czech.z5** – CZECH, the Comprehensive Z-machine Emulation CHecker, v0.8, by Amir Karger.
  `czech.out5` is its reference output. Licence (from `czech-README.txt`, reproduced unchanged as it requires):

* **praxix.z5** – Praxix, a Z-Machine unit test, by Andrew Plotkin (Zarf) and Dannii Willis. Public domain
  ("Public domain, but please share your changes so we can improve the tests"). Its "indirect" test is
  Copyright (C) 2003 Amir Karger, under the CZECH licence above.
